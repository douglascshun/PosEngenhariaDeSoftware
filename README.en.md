## About the program

I'm a Software Engineer focused on Offensive Security / Red Team and AppSec. This program covers the building side: architecture, data, cloud and project management, the foundation for designing resilient systems from the code up.

This repository is my public notebook for the program. Each class has code examples, Markdown notes and execution screenshots. The blocks below expand and collapse: module, course, class.
