## Sobre o curso

Sou Engenheiro de Software com foco em Segurança Ofensiva / Red Team e AppSec. Esta pós complementa o lado de construção: arquitetura, dados, nuvem e gestão de projetos, a base para criar sistemas resilientes desde o código.

Este repositório é o meu caderno público do curso. Cada aula tem os exemplos em código, as anotações em Markdown e os prints da execução. Os blocos abaixo abrem e fecham: módulo, disciplina, aula.
