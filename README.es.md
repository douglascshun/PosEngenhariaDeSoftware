## Sobre el posgrado

Soy Ingeniero de Software enfocado en Seguridad Ofensiva / Red Team y AppSec. Este posgrado cubre el lado de la construcción: arquitectura, datos, nube y gestión de proyectos, la base para crear sistemas resilientes desde el código.

Este repositorio es mi cuaderno público del curso. Cada clase tiene ejemplos en código, apuntes en Markdown y capturas de la ejecución. Los bloques de abajo se abren y se cierran: módulo, asignatura, clase.
